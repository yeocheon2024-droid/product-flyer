## PNG·PDF 상품 사진 누락 수정 — 2026-11-04

- 원인: R2 원본 사진 응답에 `Access-Control-Allow-Origin`이 없어 html2canvas가 외부 사진을 누락. 실제 원본 200/CORS 없음, 사진 프록시 200/CORS `*` 응답 확인.
- 저장 전에 양면의 모든 사진을 data URL로 준비하고 캡처용 복제 문서에 적용. 미리보기 화면은 변경하지 않음.
- R2 사진은 CORS 지원 경로를 우선 사용. 타 외부 사진은 원본 CORS 실패 시 프록시 재시도. 사진 중복 요청 제거·동시 4개 요청·25초 제한·용량 및 이미지 형식 검사.
- 사진 실패 시 누락된 채 저장하지 않고 상품명 포함 오류 표시. PNG는 양면 모두 준비 후 다운로드하며 중복 저장 클릭 방지.
- 자동 검사 34개 통과. 실제 R2 상품 사진·프록시 사진·사이트 원본 이미지를 data URL로 변환하는 네트워크 검사 통과. 브라우저 연결 부재로 실제 다운로드 버튼의 최종 시각 검증은 수행하지 못함.
